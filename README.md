

🎯 Project Objectives:

Analyze total sales, total profit, and profit margin.

Discover trends and insights to support business decision-making.

✅ Power BI
✅ DAX (Data Analysis Expressions)
✅ Power Query
✅ Microsoft Excel
✅ Data Cleaning & Transformation
✅ Interactive Visualizations and KPI Cards

📈 Key Learnings:
This project helped me strengthen my skills in data visualization, KPI reporting, business performance analysis, and converting raw data into meaningful insights that support data-driven decisions.
